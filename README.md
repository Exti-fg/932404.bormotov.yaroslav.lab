# Лабораторная работа №3. Верстка макета с помощью Flexbox и Grid

**Студент:** Ярослав Бормотов  
**Тема проекта:** «Эко-трекер»
**Вариант:** 7 — «Эко-активист»

## Цель работы

Освоить Flexbox и CSS Grid для построения макета веб-страницы и адаптировать его для экранов разной ширины.

## Описание проекта

Одностраничный сайт об экологичных привычках и городских инициативах. На странице есть шапка с аватаром, навигация по разделам, карточки эко-привычек, блок инициатив, форма обратной связи и подвал.

## Реализация макета

- **Flexbox:** шапка `.header` располагает аватар и заголовок в ряд; навигация `.main-nav` остаётся горизонтальной и допускает перенос ссылок; `.habit-cards` использует фиксированную долю ширины карточки с учётом промежутков, без растягивания последней карточки на всю строку.
- **CSS Grid:** `.initiative-grid` содержит три блока: «Пункты приёма», «Акции», «Карта зелёных зон». По варианту 7 из PDF на планшете и десктопе они располагаются в три колонки, на мобильном — в одну. `.contact-section` делит текст и форму на две колонки, на мобильном — на одну.
- **Адаптивность:** мобильный — до `767px`, планшет — `768–1023px`, десктоп — от `1024px`. Flex-карточки используют соответственно 1/2/3 колонки, Grid — 1/3/3. До `767px` шапка перестраивается в колонку; до `480px` уменьшаются отступы и аватар. Длинные слова переносятся, поля формы не расширяют сетку.
- **Семантическая структура:** используются элементы `header`, `nav`, `main`, `section`, `article`, `aside`, `form` и `footer`.
- **Доступность:** прогресс-бары связаны с названиями привычек, поля формы имеют видимые подписи, интерактивные элементы — выделение клавиатурного фокуса. Для номера и ссылки при наведении в тёмном блоке карты используется контрастный светлый цвет.
