## Цель работы
Освоить подключение CSS, работу с селекторами, переменными, анимациями, позиционированием и псевдоклассами.

## Что реализовано

### 1. Способы подключения CSS
- **Внешний файл** `style.css` — основные стили.
- **Внутренний `<style>`** — стили для `<footer>` (тени и выравнивание).
- **Inline-стиль** — `border-radius: 50%` для аватара.

### 2. CSS-переменные в `:root`
- `--main-color` — светло-зелёный
- `--accent-color` — тёмно-зелёный
- `--text-color` — цвет основного текста
- `--bg-color` — цвет фона
- `--font-main` — основной шрифт

### 3. Специфика Варианта 7
- **Анимация прорастания** навыков через `@keyframes` (`opacity` + `transform`).
- **Иконка листа 🌿** через `::before` при `:hover`.
- **Уменьшение `letter-spacing`** при `:active`.

### 4. Позиционирование
- `static` — у `.projects-section`
- `relative` — у `.eco-aside`
- `absolute` — у `.eco-badge`

### 5. Состояния элементов
- `:hover` — список навыков, кнопка, ссылки
- `:active` — навыки, кнопка
- `:focus` — поля формы
- `:visited` — ссылка «Мой GitHub»
