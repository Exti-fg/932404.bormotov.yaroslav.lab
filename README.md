## Задание варианта 7: потребление воды

Скрипт [script.js](./script.js) подключён к [index.html](./index.html) с `defer`: браузер запускает его после разбора HTML.

- Данные за семь дней: `[1, 1.5, 3.2, 3, 3.5, 0.5, 1]` литра.
- `prompt` запрашивает имя, `alert` показывает приветствие и итог за неделю, `console.log` выводит подробности.
- `findMax` находит максимальное значение, `filterHighConsumption` оставляет значения **строго больше 3 л**, `calculateSum` вычисляет сумму.
- `analyzeWaterConsumption` использует цикл для подсчёта дней с потреблением **не больше 1,5 л**, рассчитывает их процент и среднее потребление.
- Если среднее **строго меньше 2 л**, в консоли появляется сообщение: «Рекомендуется увеличить потребление воды до 2–2,5 литров в день». Это учебное условие из задания, а не индивидуальная медицинская рекомендация.
- `runWaterTracker` отвечает за ввод имени и вывод результатов. Отмена или пустое имя дают приветствие «Здравствуйте!» без имени, расчёт при этом выполняется.

## Пример результатов

| Показатель | Результат |
|---|---|
| Сумма за неделю | 13,7 л |
| Максимум за один день | 3,5 л |
| Значения больше 3 л | 3,2 и 3,5 л — 2 дня |
| Значения не больше 1,5 л | 1; 1,5; 0,5; 1 л — 4 дня |
| Процент дней с низким потреблением | 4 / 7 × 100 ≈ 57,14% |
| Среднее за день | 13,7 / 7 ≈ 1,96 л |
| Рекомендация | Выводится, потому что среднее меньше 2 л |
