# Лабораторная работа №3. Верстка макета с помощью Flexbox и Grid

**Студент:** Ярослав Бормотов  
**Тема проекта:** «Эко-трекер»

## Цель работы

Освоить Flexbox и CSS Grid для построения макета веб-страницы и адаптировать его для экранов разной ширины.

## Описание проекта

Одностраничный сайт об экологичных привычках и городских инициативах. На странице есть шапка с аватаром, навигация по разделам, карточки эко-привычек, блок инициатив, форма обратной связи и подвал.

## Реализация макета

- **Flexbox:** шапка `.header` располагает аватар и заголовок в ряд; навигация `.main-nav` размещает ссылки горизонтально; блок `.habit-cards` раскладывает карточки привычек с переносом на следующую строку.
- **CSS Grid:** блок `.initiative-grid` выводит карточки инициатив в три колонки; `.contact-section` делит текст и форму на две колонки.
- **Адаптивность:** при ширине окна до `760px` шапка и навигация перестраиваются, а сетки инициатив и контактов переходят в одну колонку. До `480px` уменьшаются внутренние отступы и аватар.
- **Семантическая структура:** используются элементы `header`, `nav`, `main`, `section`, `article`, `aside`, `form` и `footer`.
